# Composer (BLIP-2 QTR)

Sibling of `HBI/rerank/cr`. Implementation stays under dataset packages:

- Train CIRR: `python -m HBI.cirr.vision_desc.train_cirr_blip2_qtr`
- Train FIQ: `python -m HBI.fiq.vision_desc.train_fiq_blip2_qtr`
- Scripts: `scripts/run_train_*_blip2_qtr_stage_a.sh`

Default checkpoints: see `HBI.rerank.paths.COMPOSER_*_DEFAULT`.
